# API и восстановление

Все адреса относительные к origin приложения. POST принимает JSON-объект до 4096 **байт**, UTF-8 декодируется после сборки чанков. Ник — строка: trim, удаление управляющих символов, максимум 24 символа, минимум 2. Объект, число или массив вместо ника отклоняются.

| POST /api/... | Обязательные поля |
|---|---|
| create | пустой объект |
| join | code, name |
| answer | code, token, matchId, index, answer (0–3) |
| bingo | code, token, matchId, mission (0–7) |
| start, reveal, next, restart, close | code, token, matchId, version |
| kick | те же поля и playerId |

create/join отвечают 201 и `{code, token, role}`; остальные успешные команды — 200 и `{ok:true}`. matchId создаётся с комнатой и меняется при реванше, version увеличивается при изменениях и не обнуляется. answer намеренно не использует общую version: независимые ответы не должны конфликтовать из-за действий другой участницы. Повтор ответа не применяется.

GET /api/state?code=... и /api/events?code=... используют `Authorization: Bearer TOKEN`. Токен только в query string не авторизует запрос (403). Приглашение содержит только code. GET /api/health не расходует API-лимит. Публичный справочник включён в клиентскую сборку из src/shared/content.ts и доступен до входа. Устаревший /rules.js удалён (404).

Снимок содержит code, matchId, version, role, selfId, phase, index, total, players, bingo, missions, rules и roundComplete. В lobby/break/finished question=null; в question есть text/options/period; в reveal добавляются correct/explanation и answer/correct у игроков. Токенов в снимках нет. Корректный снимок проверяется до рендера.

SSE отправляет полный снимок при подключении и после мутации, heartbeat-комментарий раз в 20 секунд; события room-closed/session-ended содержат безопасный message. Клиент имеет одно текущее поколение потока, прекращает его в фоне и восстанавливает актуальное состояние при возврате. Таймаут отсутствия данных — 45 секунд; backoff 1,5–15 секунд, Retry-After для лимита подключений учитывается. Replay-журнал не нужен: актуальный снимок восстанавливает игровой результат.

Ошибки: `{error: string, code: string}`. Категории: 400 invalid_request (включая тело >4096 байт), 403 forbidden, 404 not_found, 409 conflict, 429 rate_limited с Retry-After, 500 internal_error с безопасным текстом. Неожиданные ошибки не возвращают stack или секреты. На Origin чужого сайта возвращается 403.

Старые страницы без matchId/index/version получают отказ и просьбу обновить страницу. POST при таймауте не повторяется автоматически: сначала запрашивается актуальное состояние. Локальная подсветка ответа привязана к захваченным matchId/index/selfId и не влияет на счёт. Повреждённая сессия удаляется; недоступное хранилище показывает предупреждение без обещания восстановления после закрытия вкладки.
